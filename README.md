Extender ist eine browserbasierte Web-App auf Basis von p5.js, mit der sich Bildränder gezielt erweitern und bearbeitete Bilder direkt als dateiname_ext im Download-Ordner speichern lassen.  

[![Buy Me A Coffee](https://img.shields.io/badge/Buy%20Me%20a%20Coffee-DFFF00?style=for-the-badge&logo=buy-me-a-coffee&logoColor=black)](https://www.buymeacoffee.com/khz66)

​Extender erweitert bestehende Bilder lokal im Browser um eine frei wählbare Pixelanzahl an einer oder mehreren Seiten. Dabei stehen transparente Hintergründe, automatisch ermittelte Randfarben sowie eigene Wunschfarben zur Verfügung.  
​Funktionen im Überblick:
​Stapelverarbeitung: Mehrere Bilddateien lassen sich gleichzeitig auswählen und nacheinander bearbeiten.
​Flexible Erweiterung: Die Ränder können oben, unten, links und/oder rechts (standardmäßig unten mit 200 Pixeln) vergrößert werden.
​Hintergrundoptionen: Wahl zwischen transparentem Hintergrund (Alpha erhalten, bei JPG/JPEG automatisch als PNG), automatischer Farberkennung vom Bildrand oder eigener Farbwahl per Farbwähler.
​Live-Vorschau & direkter Download: Ein p5.js-Canvas zeigt den Ablauf und eine Vorschau an; fertige Bilder werden automatisch als dateiname_ext (PNG, JPG oder WebP) heruntergeladen.

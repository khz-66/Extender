Extender erweitert Bildränder auf einer oder mehreren Seiten und speichert bearbeitete Bilder im Download-Verzeichnis.

Die browser-basierte Web-App ​Extender erweitert bestehende Bilder um eine frei wählbare Pixelanzahl an einer oder mehreren Seiten. Dabei stehen transparente Hintergründe, automatisch ermittelte Randfarben sowie benutzerdefinierte Farben zur Verfügung.  

# ​Funktionen im Überblick
**Stapelverarbeitung:** Mehrere Bilddateien lassen sich gleichzeitig auswählen und nacheinander bearbeiten.

**​Flexible Erweiterung:** Die Ränder können oben, unten, links und/oder rechts (standardmäßig unten mit 200 Pixeln) vergrößert werden.

**​Hintergrundoptionen:** Wahl zwischen transparentem Hintergrund (Alpha erhalten, bei JPG/JPEG automatisch als PNG), automatischer Farberkennung vom Bildrand oder eigener Farbwahl per Farbwähler.

​**Download:** Fertige Bilder werden automatisch als dateiname_ext (PNG, JPG oder WebP) ins Download-Verzeichnis heruntergeladen.
